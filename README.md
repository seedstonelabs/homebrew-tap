# Homebrew tap for SeedStone

An in-memory key-value store speaking the Redis protocol, with optional persistence.

```sh
brew install seedstonelabs/tap/seedstone
```

The formula is published here by the release workflow of
[stefanobaldo/seedstone](https://github.com/stefanobaldo/seedstone) on every
final release; it is not edited by hand. Installation and service notes:
[docs/install.md](https://github.com/stefanobaldo/seedstone/blob/main/docs/install.md).
